HOW TO USE
1. Extract this folder.
2. Open the folder in VS Code or use Command Prompt and run a practical:
   python Practical_01_BFS_IDFS.py
3. Replace 01 with the practical number you want to run.

INSTALL REQUIRED LIBRARIES
Run this command in Command Prompt:
python -m pip install pandas scikit-learn matplotlib mlxtend

For Practical 10, install TensorFlow separately:
python -m pip install tensorflow

IMPORTANT DATASET NOTES
- Practical 05 requires diabetes.csv in this same folder. The CSV must have an Outcome column.
- Practicals 01, 02, 03, 04, 06, 07 and 08 use built-in or code-created data.
- Practical 09 uses a small transaction dataset written inside the code.
- Practical 10 downloads MNIST through TensorFlow on first run and needs internet.
